# LiquidHaskell CHCs

A curated set of **320 saved Fixpoint queries** and their generated Lean validity
statements. Relative paths and basenames match between the two directories:

- `fixpoint-queries/tests/…/Name.fq`: original query, unchanged.
- `lean-chc-queries/tests/…/Name.lean`: generated definitions ending in `FixpointGoal`.
- `manifest.json`: file hashes, upstream revisions, features, and selection provenance.

The set contains all 268 successes from an earlier Flex run, plus 26 smaller
partial cases with predicate elimination and 26 smaller timeouts. The latter
categories are ordered by clause count, predicate count, generated bytes, and
case name. This is an **outcome-selected development suite**, not a random sample
for estimating LiquidHaskell-wide coverage. A later run with a 30-second shared
Flex budget proved 255 and instantiated all predicates in 282; the manifest
retains those historical results separately from the selection outcomes.

Each file has its own `FixpointGoal`; check files separately. Background functions
are universally quantified, original refinement variables are existentially
quantified, and explicit theory laws become assumptions. The files contain no
invariant witnesses or proof templates. Statement checking establishes Lean
well-formedness, not a proof of the CHC or of translation correctness.

## Check

From this directory, install the pinned dependencies once:

```sh
lake update
lake exe cache get
lake build
```

From the repository root:

```sh
python3 tooling/liquid-haskell/corpus.py check
python3 tooling/liquid-haskell/corpus.py check --lean
```

An existing Flex checkout can supply the Lean/Mathlib environment instead:

```sh
python3 tooling/liquid-haskell/corpus.py check --lean --lean-project ../Flex
```

See [the tooling instructions](../tooling/liquid-haskell/README.md) for capture and
conversion. Inputs originate from LiquidHaskell commit
`7c809b687388dc837c53b9db29b0a70b7165b716`; the upstream license is retained in
[LICENSE](LICENSE). The saved `.fq` configuration header is part of each input.
